## 개요
2023년 3월 4일 기준 github 계정 생성하는 방법에 대해서 정리한 내용입니다. 

## 진행순서
진행 순서는 아래와 같습니다.

- https://github.com/ 사이트에 접속합니다.

- Sign up 아이콘을 클릭합니다.
  {% asset_img img3.jpg 회원가입 %}

- 이메일 주소 패스워드 이름을 메일 수신여부 y 입력하고 Continue 버튼을 클릭합니다. 
  {% asset_img github10.png 이메일주소입력 %}

- 같은 그림 2개가 들어가 있는 이미지를 선택합니다.
  {% asset_img github11.png 같은그림선택하기 %}

- 그림인증이 끝나고 나면 아래와 같은 화면이 나오고 Create account 버튼을 클릭하여 다음단계를 진행합니다.
  {% asset_img github12.png 인증성공 %}

- 등록한 이메일로 아래와 같은 인증 코드 복사한후 Enter Code 부분에  인증코드를 붙여넣기 합니다.
  {% asset_img github14.png 이메일인증코드 %}
  {% asset_img github13.png 인증코드등록 %}

- __여기까지 진행하면 계정생성이 완료됩니다.__
  {% asset_img github15.png 계정생성완료 %}
  
> 계정을 생성할때 음성으로 질문하는 경우도 있습니다. 음성에서 사람소리가 들리는데 몇번 말했는지 숫자를 적어주면 다음단계로 진행할수 있습니다.
