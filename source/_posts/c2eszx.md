이번에 Hexo 블로그 디자인을 전체적으로 바꿔보려고 한다. 홈만 바꾸는 데서 끝내지 않고 글 상세, 카테고리, 태그, 아카이브, 소개와 검색 화면까지 함께 정리할 생각이다.

글 제목만 나열하지 않고 이미지와 짧은 요약을 함께 보여주고 싶다. 방문자가 홈에서 새 글을 쉽게 발견하고, 카테고리나 검색으로 필요한 글을 바로 찾을 수 있도록 만드는 게 이번 개편의 목표다.

![AI 도구와 함께 개발하는 작업 환경](/images/ai-developer.png)

## 이렇게 바꾸려고 한다

- 어느 페이지에 들어와도 메뉴와 글꼴, 색상, 본문 폭이 자연스럽게 이어지도록 한다.
- 첫 화면에서 대표 글과 새 글을 이미지, 제목, 요약으로 소개한다.
- 카테고리나 태그, 검색으로 원하는 글을 쉽게 찾을 수 있게 한다.
- 글 상세 화면은 제목과 요약부터 본문, 관련 글까지 읽기 편한 순서로 정리한다.
- 지금까지 쓴 글의 내용과 주소는 유지한다.
- 휴대폰으로 봐도 메뉴나 이미지, 표가 답답하지 않도록 살펴본다.

## 바꿀 페이지

| 페이지 | 바꾸려는 내용 |
| --- | --- |
| 홈 | 대표 글과 새 글을 이미지와 요약으로 보여주고, 주제별 글도 찾기 쉽게 나눈다. |
| 글 상세 | 제목, 요약, 작성일, 대표 이미지와 본문을 읽기 편하게 배치한다. 글자 크기 조절, 인쇄, 관련 글도 챙긴다. |
| 카테고리 전체 | 카테고리를 검색하고, 글 수와 최근 글을 확인할 수 있게 한다. |
| 개별 카테고리 | 어떤 주제의 글인지 간단히 소개하고 해당 글들을 보여준다. |
| 태그·아카이브 | 태그나 연도, 월별 글 목록을 같은 방식으로 정리한다. |
| 소개·검색·오류 페이지 | 다른 페이지와 어울리도록 디자인을 맞추고, 필요한 안내를 보여준다. |
| 별도 화면 | Hexo와 따로 만들어진 화면도 살펴보고 사이트 분위기에 맞춘다. |

## 전체 페이지에서 공통으로 쓸 것

위쪽에는 로고와 주요 메뉴, 검색을 두고, 글 목록이나 카테고리로 바로 갈 수 있게 한다. 본문 위에는 지금 어느 페이지에 있는지 표시하고, 아래쪽에는 소개와 아카이브로 가는 링크를 둔다.

글을 볼 때 제목과 요약, 분류, 날짜가 한눈에 구분되도록 크기와 간격을 정리한다. 파란색을 중심으로 쓰되 화면이 너무 무거워지지 않게 하고, 글이나 이미지가 바뀌어도 사이트 전체가 하나처럼 보이도록 맞춘다.

## 이미지와 글 정보도 정리하기

글마다 대표 이미지와 짧은 요약을 붙일 수 있도록 기준을 정한다. 이미 본문에 이미지가 있는 글은 내용을 확인해 대표 이미지로 쓸 수 있는지 살펴본다. 쓸 이미지가 없는 글에는 카테고리에 어울리는 기본 이미지를 보여준다.

이미지가 안 뜨더라도 제목과 요약만으로 무슨 글인지 알 수 있어야 한다. 이미지에는 내용을 설명하는 글을 넣고, 필요한 경우 사진 설명이나 출처도 함께 적는다.

## 진행 순서

1. 먼저 어떤 페이지와 템플릿을 바꿔야 하는지, 별도 정적 화면까지 포함해 목록으로 정리한다.
2. 공통 메뉴와 푸터, 색상, 글꼴, 본문 폭을 정한다.
3. 홈과 글 상세를 먼저 바꾸고 카테고리, 태그, 아카이브, 소개, 검색 화면도 이어서 맞춘다.
4. 글마다 대표 이미지와 요약을 연결하고 이미지가 없을 때 쓸 기본 규칙을 정한다.
5. 컴퓨터와 휴대폰에서 메뉴, 검색, 페이지 이동, 관련 글, 인쇄가 잘 보이는지 확인한다.
6. 마지막으로 사이트를 생성해 보고 기존 주소와 이미지, 페이지 이동, 404, 별도 정적 화면이 잘 나오는지 확인한다.

우선 공통 디자인을 정한 다음 홈과 글 상세처럼 자주 보는 화면부터 바꾸면 좋겠다. 그다음 목록과 나머지 페이지를 맞추고, 이미지와 요약을 정리한다. 모바일과 주소 확인은 전체 화면을 연결한 뒤 마지막에 한 번 더 살펴볼 생각이다.

## 다 바뀌면 이 정도는 확인하기

- 어느 페이지에서든 메뉴와 디자인이 자연스럽게 이어진다.
- 홈과 글 목록에서 이미지, 제목, 분류, 날짜, 요약을 확인할 수 있다.
- 카테고리, 태그, 아카이브, 검색을 통해 예전 글도 찾을 수 있다.
- 휴대폰에서도 글을 읽고 메뉴를 이동하기 편하다.
- 기존 글 내용과 주소가 그대로 유지되고, 이미지나 링크가 깨지지 않는다.
