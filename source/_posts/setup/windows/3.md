### {% fa cloud %} oracle 21c 사용자 생성방법


oracle 21c 에서 사용자 생성하는 방법은 아래와 같다.


오라클 21c 에서 계정을 생성할때는 c## 붙여야 하므로 이를 붙이지 않기 위해 아래와 같이 설정한다.

```sql
ALTER SESSION SET "_ORACLE_SCRIPT"=TRUE;
```

아래 명령어로 오라클 사용자를 생성한다.

```sql
CREATE USER GOODSAEM IDENTIFIED BY goodsaem;
```

생성한 사용자의 db 접속권한과 자원을 사용할수 있도록 권한을 부여한다.

```sql
GRANT CONNECT, RESOURCE TO GOODSAEM;
```

USERS 테이블 스페이스를 사용할수 있도록 권한을 부여한다.

```sql
ALTER USER GOODSAEM DEFAULT TABLESPACE USERS QUOTA UNLIMITED ON USERS;
```
