mac intellij 환경에서 코드를 정리하는 단축키는 아래와 같다.

```shell
option + command + L
```


***코드 정리전***
```shell
<table>
<tr>
<td>
asdasdfasdfdsf</td>
</tr>
</table>
```

***코드 정리후***
```shell
<table>
    <tr>
        <td>
            asdasdfasdfdsf
        </td>
    </tr>
</table>
```
